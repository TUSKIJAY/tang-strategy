## 1. 基本配置

| 项目 | 值 |
|------|-----|
| 标的 | SPY（SPX / QQQ 同理） |
| K 线类型 | **Heikin-Ashi**（平均 K） |
| 主图（进出场） | **1 分钟** |
| 副图（大方向） | **5 分钟** |
| 均线类型 | 全部 **SMA** |
| 交易时间 | RTH 09:30–16:00 ET |
| 建议等待开盘稳定 | 10:00–10:30 后再找信号 |

### 均线体系

| 均线 | 分类 | 作用 |
|------|------|------|
| **MA10** | 核心 | 唯一触发进出场的线，整套系统灵魂 |
| MA20 / MA30 | 辅助 | 判断排列方向，力度弱，不作主要依据 |
| **MA50** | 关卡 | 强支撑/阻力，信号 B 的额外确认条件 |
| **MA200** | 关卡 | 多空终极分界，远离时下方空间最大 |
| **VWAP** | 关卡 | 当日多空背景确认，与 MA50/MA200 同等对待 |

### Heikin-Ashi 计算（PineScript 精确定义）

```
ha_close = (open + high + low + close) / 4
ha_open  = na(ha_open[1]) ? (open + close) / 2 : (ha_open[1] + ha_close[1]) / 2
ha_high  = max(high, ha_open, ha_close)
ha_low   = min(low, ha_open, ha_close)
```

- 均线基于 **ha_close** 计算：`SMA(ha_close, N)`
- VWAP 基于 **原始 close** 计算：`ta.vwap(close)`
- 5 分钟均线基于 **5 分钟 HA close** 计算

### HA K 线视觉特征

- **下跌趋势**：红 K 只有下影线（无上影线）
- **上涨趋势**：绿 K 只有上影线（无下影线）
- **趋势衰竭**：影线开始变长 → 准备出场

## 2. 核心逻辑

> **趋势已经成型 → 等信号 → 顺势进场 → 趋势破坏立刻出场**
>
> 不预测方向，只等确认。顺延永远比反转容易。不做反手，不猜底，不猜顶。

### 趋势判定

#### 5 分钟趋势（司令部 — 决定大方向）

```python
# 极其严苛的完美发散条件
bearish_5m = (MA10_5m < MA20_5m) and (MA20_5m < MA50_5m) and (MA50_5m < MA200_5m)
bullish_5m = (MA10_5m > MA20_5m) and (MA20_5m > MA50_5m) and (MA50_5m > MA200_5m)
```

- **多头排列**：价格 > MA10 > MA50 > VWAP > MA200，向上发散 → 找 CALL
- **空头排列**：MA200 > VWAP > MA50 > MA10 > 价格，向下发散 → 找 PUT
- 5 分钟没有趋势 = **等，不动**

#### 1 分钟 K 线状态

```python
is_green = ha_close >= ha_open
is_red   = ha_close < ha_open
```

## 3. 信号 A — Reject / Support MA10

> 日常主力信号，一天可出现多次。下方有关卡时快进快出。

### Reject MA10（空头信号 → 买 PUT）

**条件**（全部必须满足）：

```python
touch_ma10_up   = ha_high >= ma10        # 上影线触及 MA10
body_below_ma10 = (ha_close <= ma10) and (ha_open <= ma10)  # 实体在 MA10 下方
reject          = is_green and touch_ma10_up and body_below_ma10
```

**形态描述**：空头排列中，绿 K 反弹，上影线碰到 MA10 但实体没穿过 → 被 MA10 压回

**进场确认**：Reject K 收完后，下一根 K 是红 K → 进场买 PUT

### Support MA10（多头信号 → 买 CALL）

**条件**（全部必须满足）：

```python
touch_ma10_down = ha_low <= ma10         # 下影线触及 MA10
body_above_ma10 = (ha_close >= ma10) and (ha_open >= ma10)  # 实体在 MA10 上方
support         = is_red and touch_ma10_down and body_above_ma10
```

**形态描述**：多头排列中，红 K 回调，下影线触到 MA10 但实体没跌穿 → 被 MA10 撑住

**进场确认**：Support K 收完后，下一根 K 是绿 K → 进场买 CALL

### 跨周期共振触发（PineScript 精确逻辑）

```python
signal_put  = bearish_trend_5m[1] and reject_1m[1] and is_red   # 前一根5分钟空头 + 前一根1分钟Reject + 当前红K
signal_call = bullish_trend_5m[1] and support_1m[1] and is_green # 前一根5分钟多头 + 前一根1分钟Support + 当前绿K
```

### 无效情况（不可进场）

- 反弹/回调 K **没有碰到 MA10** → 不算 Reject/Support
- 实体**完全穿过** MA10 → 无效
- K 线开盘是红但收盘变绿（或反之）→ 无效，等收完
- 反弹绿 K 太长太强 → 多头力量强，不适合做空
- K 线未收完 → 不进场

## 4. 信号 B — 大空间信号

> 本质与信号 A 相同（Reject MA10），但多了额外条件，使得下方空间更大。

### 五步条件（缺一不可）

1. **空头排列成型**
2. **先出现 2–3 根红 K 的 setup**
3. **Reject MA10，且那根 K 同时跌破 MA50**
4. **下方 VWAP 和 MA200 都离得很远**（无关卡拦截）
5. **5 分钟 K 线图确认**（形成支撑或跌破，近处没有关卡）

### 止损

- 价格实体收回 MA50 上方 → 立刻出场

### 目标位

- 下方最近关卡（VWAP 或 MA200），分批止盈

### 特别规则

- 第一根绿 K 出现后**绝对不追**
- 均线缠绕时**绝对不做**，等发散

---

## 5. 均线缠绕 — 禁区

### 判定标准

- MA10、MA20、MA50 **挤在一起**，价格来回穿越
- K 线两侧都有长影线，红绿交替
- 无清晰方向

### 规则

- **绝对不做**，等均线清晰发散、排列稳定后再找进场点
- 缠绕期间进场没有依据

---

## 6. K 线质量判断

| 特征 | 趋势强（可持仓） | 趋势弱（准备出场） |
|------|:---:|:---:|
| 实体 | 大/肥实心柱 | 变小 |
| 影线 | 极短，单侧 | 变长，双侧出现 |
| 颜色 | 连续同色 | 红绿交替 |
| 新高/新低 | 持续创新 | 不再创新 |

---

## 7. 三条关卡（MA50 / MA200 / VWAP）

> 本质相同，都是有实质力度的支撑/阻力关卡。用途一样，只是强度不同。

### 进场前 — 空间判断

- 目标方向最近的关卡在哪里？
- 进场后没走几步就碰到 → **空间太小，不做**

### 持仓中 — 关卡警惕

- 持 PUT 接近 MA50/MA200/VWAP → 小心支撑反弹，准备减仓
- 持 CALL 接近这三条线 → 小心阻力压制，准备减仓

### MA200 特殊地位

- 价格在 MA200 上方 → 多头背景，优先找 CALL
- 价格在 MA200 下方 → 空头背景，优先找 PUT
- 价格在 MA200 附近反复 → **不做或极轻仓**

### 双重确认

- Reject MA10 同时 Reject VWAP → 信号更强

---

## 8. 1 分钟 + 5 分钟配合流程

1. **先开 5 分钟图** → 确认大方向。5 分钟没有趋势 = 等
2. **看 5 分钟关卡位置** → 目标方向有紧挨着的关卡？太近不做
3. **切换 1 分钟图** → 等 MA10 的 Reject 或 Support，K 线收完确认
4. **进场后** → 1 分钟盯 MA10，5 分钟影线变长就警惕出场

### 持仓时间判断

- 5 分钟连续大实心 K + 均线极度发散 → 可多拿几根 K
- 5 分钟趋势一般 → 快进快出

---

## 9. 进场前八步检查

> 任何一条让你犹豫，答案就是**不做**。

| # | 检查项 | 不通过则 |
|---|--------|----------|
| 1 | 5 分钟有趋势吗？排列清晰发散？ | 停手 |
| 2 | 均线有缠绕吗？MA 线缠在一起？ | 不做，等发散 |
| 3 | VWAP 站哪边？和趋势方向一致？ | 警惕 |
| 4 | 目标方向有关卡拦着吗？MA50/MA200/VWAP 太近？ | 不做 |
| 5 | MA10 给信号了吗？影线/实体真正触及 MA10？ | 等 |
| 6 | 确认 K 收完了吗？ | 等 |
| 7 | K 线质量好不好？影线变长、实体变小？ | 等下一根 |
| 8 | IV 高不高？ | 更挑剔或不做 |

## 10. 止损规则

> **进场逻辑 = 出场逻辑。进场的理由消失，立刻出场。没有"再等等"。**

| 进场原因 | 止损条件（立刻出） |
|----------|-------------------|
| 空头排列 Reject MA10 买 PUT | 绿 K 实体完全突破 MA10 |
| 多头排列 Support MA10 买 CALL | 红 K 实体完全跌破 MA10 |
| 信号 B（Reject MA10 + 跌破 MA50） | 价格实体收回 MA50 上方 |
| 跌破 MA200 做空 | 价格实体收回 MA200 上方 |
| 突破 MA200 做多 | 价格跌破 MA200 |

### 止损算法（PineScript）

```python
# 只有在持仓状态下才触发止损
stop_loss_put  = position == -1 and is_green and (ha_close > ma10) and (ha_open > ma10)
stop_loss_call = position ==  1 and is_red   and (ha_close < ma10) and (ha_open < ma10)
```

## 11. 止盈规则

1. **分批止盈** → 分 2–3 次出，不要一次全卖
2. **趋势衰竭信号出现时减仓** → 影线变长、不再创新低/高、红绿交替
3. **接近 5 分钟关卡减仓** → MA50、MA200、VWAP 附近分批出
4. **尾盘不贪** → 有利润就走
5. **Robinhood 注意** → 必须在下跌/上涨过程中卖出，回头卖会滑点严重

---

## 12. 绝对不做的情况

| 条件 | 原因 |
|------|------|
| 5 分钟无趋势，均线缠绕 | 无方向依据 |
| 均线关卡群内来回穿越 | 无法判断方向 |
| 价格在 MA200 附近反复 | 多空胶着 |
| 开盘前 30 分钟（9:30–10:00） | 通常震荡 |
| 连续长影线，红绿交替 | 趋势衰竭 |
| IV 太高 | 风险收益比差 |
| 看不明白当前情况 | 无依据 |
| 进场点离关卡太近 | 空间不够 |
| 趋势已走很长 | 不吃鱼尾 |
| 刚做错一单心态不稳 | 防止报复性交易 |
| 没想清楚进场理由 | 无逻辑 |

### 开盘例外

- 开盘直接出现两根大阳/大阴柱突破 MA200 → 可考虑跟进，但需 1 分钟确认

---

## 13. 仓位管理

- 每天 **1–2 单**，最多不超过 3 单
- 不确定 → 轻仓
- 信号极完美 → 正常仓位
- 亏损状态 → 绝对不加仓、不充值

---

## 14. 每日复盘流程

1. **重点复盘做对的单** → 从盈利单中找自己的模式
2. **标记当天所有符合条件的信号** → 进了哪个，漏了哪个，为什么
3. **分析亏损原因** → 90% 是"没按策略"或"急了"
4. **记备忘录** → 把符合标准的图记下来
5. **每天说一遍** → 没看到关键信号，不参与
