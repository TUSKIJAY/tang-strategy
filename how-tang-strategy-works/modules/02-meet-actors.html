代码在说什么：双模式入口

同一个仓库能跑两种「放映厅」：交互 App，或静态 Pages。

CODE 
createRoot(document.getElementById('root')).render(
  import.meta.env.VITE_STATIC_REVIEWS === 'true' ? <StaticReviewsApp /> : <App />,
);
PLAIN ENGLISH

在页面 root 节点挂上 React 根。

若环境变量 VITE_STATIC_REVIEWS 为 true → 渲染 StaticReviewsApp。

否则渲染完整 App（含登录与动态 API）。

静态模式不该去改 LoginPage 流程——那条路根本不走。

⚠️
所有权提醒

静态 Pages 路径吃的是导出 JSON + StaticReviewsApp；交互路径才有 Login 与 FastAPI 实时 assemble。

代码在说什么：FastAPI 登场

后端先创建应用并挂上 CORS，再注册各业务路由。

CODE 
app = FastAPI(title="Tang Strategy API")
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=False,
    allow_methods=["*"],
    allow_headers=["*"],
)
PLAIN ENGLISH

创建名为 Tang Strategy API 的 FastAPI 应用。

挂上 CORS 中间件，让浏览器前端能跨源访问。

允许任意来源、方法与头；不携带凭证 cookie。

这是场务的「开机仪式」——真正的 assemble 路由在别处注册。
