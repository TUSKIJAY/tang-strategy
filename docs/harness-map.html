检查器层 三个专职检查器 + 14 个 fixture 单测

check-project-harness.py check-operating-modes.py check-startup-doc-budget.py scripts.tests.test_operating_modes ×14
  • harness：22 个必需文件；config schema；GitHub 契约双向核对（workflow job 显示名 ≡ config.checks，逐项按序）；9 个索引页全部链接目标存在且不逃出仓库根；内嵌调用生命周期检查器

  • doc-budget：预警 = 归档 / 去重义务，硬上限 = CI 红；PROGRESS 按正文条目数直判（>10 触发归档，不再用字节代理）；HANDOFF 预算重定为预警 4,096 / 上限 12,288
