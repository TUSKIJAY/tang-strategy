机器契约层 唯一事实源 + 跨平台执行器

.harness/config.json 是全仓库唯一的验证命令清单（11 条）与 GitHub 契约；scripts/verify.py 读取并通过 bash 执行，Windows / macOS 用法一致。

.harness/config.json scripts/verify.py
  • 清单不在任何文档里复述；INSTRUCTIONS / HANDOFF / PR 模板只留一行指引
  • verify.py --list / --only <substr> / --verbose；任一命令失败退出码非零
verify.py 执行清单 · 检查器逐项校验 ↓
3

检查器层 三个专职检查器 + 12 个 fixture 单测

check-project-harness.py check-operating-modes.py check-startup-doc-budget.py scripts.tests.test_operating_modes ×12
  • harness：22 个必需文件；config schema；GitHub 契约双向核对（workflow job 显示名 ≡ config.checks，逐项按序）；9 个索引页全部链接目标存在且不逃出仓库根；内嵌调用生命周期检查器
  • operating-modes：plan 唯一归属（proposed / active / completed 恰一处）、必需元数据、review verdict 链接、PROGRESS 与 HANDOFF 状态块逐字段相等
  • doc-budget：预警 = 归档 / 去重义务，硬上限 = CI 红
CI 三个 job 复跑同一批检查 ↓
