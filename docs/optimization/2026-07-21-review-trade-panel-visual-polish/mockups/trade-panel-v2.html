当前丑在哪

  • 点位区仍是套在侧栏里的表单卡片：外框 + 原生 select 语感 + 全宽 Download CTA。
  • 英文标签 Eligibility / Download JSON + 3 CSV / Show legs/events 与上方中文终端控件两套语言。
  • 交易者 chip 用强描边 active，像独立控件，不像同一工具条的一部分。
  • 卡片信息挤在一行：名字、方向、日期、result、badge、drill 层级不清。

v2 改什么

  • 去框套框：工具区与上方 context 同平面，仅用分区标题分隔。
  • Eligibility 三段：保持英文 Display / Reported / Calculated （对应 live option 语义；enum 不变）。
  • Download 收角：图标 + 短文案 Download；去掉整行 JSON + 3 CSV，无 hover 说明。
  • 其它原英文：Show legs/events、Verified 等不译中文。
  • 交易者 pill：B chip 多选；≤6 inline，≥7 summary + Edit drawer。
  • 卡片分层：方向轨 + 名字/PUT·CALL 徽章 + meta + 绿点状态；腿/事件可展开。
  • 表面：Review + Static + Admin 共享组件同批对齐。
锁定不改：B chip 可见性权威、CALL/PUT 方向色、名字不染色、 当日可用交易者才出现、无 ticker/date 镜像、不碰 DB/export 文件内容契约。 中文仅保留人名/既有中文提示（如「提示 · 7 进场…」），不把产品英文 chrome 汉化。

Eligibility 文案对照

  • Display → display_eligible（live: Display）
  • Reported → reported_stats_eligible（live: Reported stats；分段用短标签）
  • Calculated → calculated_stats_eligible（live: Calculated stats；分段用短标签）
弃用：中文「显示/已报/计算」「可见点位/手填收益/系统核算」——用户要求 mock 保持原英文。

已锁定 · 无待拍板

  • Mock 视觉方向认可。
  • 产品控件保持英文：Eligibility / Display·Reported·Calculated / Download / Show legs/events。
  • Download：短标签 only，去掉 JSON + 3 CSV。
  • 规模：≤6 inline pills；≥7 summary + Edit drawer。
  • 表面：Review + Static + Admin 对齐。
