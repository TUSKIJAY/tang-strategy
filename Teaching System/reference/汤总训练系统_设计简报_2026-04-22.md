## 一、项目一句话

用已有的 K 线引擎 v2 做底座，把一本叫《小汤交易攻略》的 SPY 期权剥头皮策略手册，变成**反教条的三模式训练系统**（阅读 / 观摩 / 练习），供初学者边读边做。

---

## 二、用户画像

一个想学 SPY 期权剥头皮策略的普通交易者：
- **不懂量化代码**，没法验证 Claude 给出的技术性判断对不对
- 已经读过一遍"小汤攻略"手册，需要带实例和练习的系统加深
- 需要**防过度自信**：任何"标准答案"都得带上不确定性标签

所以 UI 不是"电子教科书"，是**让学习者保持怀疑的容器**。

---

## 三、三种模式（3 个主界面）

### 1. 阅读（Read）
升级版图文攻略。核心是"章节 + 可展开的技术细节卡片"。

- 主区：章节正文（`rule` / `warning` / `danger` / `ok` 四种语义块）
- 内嵌：示意图（SVG）+ 实盘参考段
- 侧栏/抽屉：当前章节挂接的 cards（点开看"灰色地带"和"长得像但不是"）
- 链接：跳转"观摩模式"看该章节的真实案例

### 2. 观摩（Watch）
把 K 线引擎 v2 当主角，叠加讲解层。

- 主区：K 线引擎 v2（**深色 Canvas**，用户用 1m/5m 切换、播放、滚动）
- 顶部：case 标题 + 挂接的 chapter 按钮 + 挂接的 card 按钮
- 底部：checkpoints 列表（八步清单每步 pass/fail + 原因），跟着播放进度更新
- 交互：点 annotation pin 看解读；点 chapter 回阅读模式；点 card 弹卡片

### 3. 练习（Practice）
A/B/D 三种题型 + 三档判分反馈。

- **A · 盲盒预测**：K 线截到信号点 → 选"多/空/不做" → 播放后续几根 → 三档判分
- **B · 找信号**：在完整回放里圈"这里是 Reject MA10" → 对比答案
- **D · 八步填空**：按八步清单逐条答 → 指出第几步卡住
- **三档判分面板**（核心视觉）：
  - optimal 绿 / reasonable 橙 / wrong 红（**低饱和**，不荧光）
  - 每档一句 ≤ 40 字 tutor 话术（大字）
  - 展开能看详细 why_md
  - wrong 档加一条"为什么容易被骗到这里"
- **"味儿不对"按钮**：常驻右上角，一键标记"这道题 Claude 可能错了"

## 四、四类内容对象（每个对应一种 UI 容器）

| 对象 | UI 容器 | 关键字段（对设计相关） |
|---|---|---|
| **Chapter 章节** | 主阅读页 | `title`, `subtitle`, `sections[]`, `linked_*` |

- `source`：`tang_doc§3` / `real_chart_analysis Fig 2` / `claude_inference`
- `status`：`published` / `draft`

## 五、认知校验防线（**必须在 UI 上看得见**）

整个系统的灵魂约束，不能隐藏：

### 1. Source badge
每个内容块（章节段落、卡片、案例、练习题）右上角一个小标签，告诉用户来源：

| source 值 | 标签文案 | 建议视觉 |
|---|---|---|
| `tang_doc§X` | 原话 | 蓝底 + 书籍图标 |
| `real_chart_analysis Fig N` | 实盘 | 紫底 + 图表图标 |
| `claude_inference` | Claude 推论 | 橙底 + **降低饱和度**，视觉上明显弱一级 |

### 2. Draft 水印
`status: draft` 的内容整体降饱和 + 加一个斜纹底纹，一眼能分辨"这是 Claude 草稿，还没被人审过"。

### 3. "味儿不对"按钮
所有 card / exercise 的右上角有一个小按钮——**不是肉眼优先，但一找就能找到**。点了把这条记入"待修清单"。

- **不要做成"举报"式的红色**，做成克制的灰/米色
- 点击后的反馈文案要轻松："记下了，下次回来看"
- 不需要让用户说"哪里错了"，只是 flag

### 4. 三档判分的颜色纪律
三档之间必须有**明显区分**，但都用低饱和色系：

- **不要用** 🟢🔴 emoji 或荧光红荧光绿
- 建议（从秘籍 HTML 继承）：
  - optimal = `#1d7a4a`（深绿）
  - reasonable = `#7a4a0a`（琥珀）
  - wrong = `#9e2a1a`（深红）

## 六、视觉 DNA

### 6.1 继承（从 `汤总秘籍图文版.html`）
- 米色纸质感背景：`#f9f7f3` / `#f2efe9`
- 字体：Noto Sans SC + JetBrains Mono 双字体组合（中文正文 + 英文/数字/代码）
- 语义色块：蓝=rule、琥珀=warning、红=danger、绿=ok
- 卡片式信息块，不用阴影，用 1px 边框
- 章节头用小圆徽（见秘籍的 `.ch-n` 样式）

### 6.2 核心视觉张力（需要你解）
**阅读模式"米色纸张" vs 观摩模式"深色 Canvas"** — 这是系统最大的视觉冲突。

候选方案：

- **方案 A**：观摩模式"画框式"嵌入，深色 Canvas 外包一层米色边框（折中，保留阅读氛围）
- **方案 B**：观摩模式整体切换到深色主题（更沉浸，但割裂感）
- **方案 C**：K 线引擎做成"实时反色"浅色版（实现成本高，不推荐 MVP）

**请拿方案 A 做主方案，方案 B 做对照稿**，给出推荐理由。

### 6.3 硬约束（`个人设计语言规范.md` 摘要）

禁止：
- box-shadow
- 渐变背景
- 纯黑 `#000` / 纯白 `#FFF`
- 同一页面超过 3 种色相
- 高饱和荧光色 / 霓虹色
- 超过 3 行的文字居中对齐

8px 网格：`4 | 8 | 16 | 24 | 32 | 48 | 64 | 96 | 128 px`

强调色（如橄榄 `#8B9A6D`）每页最多 2~3 处。
