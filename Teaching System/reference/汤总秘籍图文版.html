核心逻辑
趋势已经成型 → 等信号 → 顺势进场 → 趋势破坏立刻出场
不预测方向，只等确认。顺延永远比反转容易。不做反手，不猜底，不猜顶。

03
进场信号A — Reject / Support MA10
日常主力信号，一天可出现多次。下方有关卡时快进快出。
空头排列 → Reject MA10 → 买PUT（绿K上影线必须真正碰到MA10）
多头排列 → Support MA10 → 买CALL（红K下影线必须真正触及MA10）
无效的情况：红K（做多时）或绿K（做空时）根本没有碰到MA10就自己反弹 → 这不是有效的Support/Reject，不能进场。影线或实体必须真正触及MA10才算数。
注意事项
  • 必须等确认K完整收完再进，不能看到一半就下单
  • 影线触及MA10但实体没穿过 = 有效信号
  • 实体完全穿过MA10 = 无效，不做
  • 那根K开盘是红但收盘变绿 = 无效，不要被骗
  • 反弹/回调没有碰到MA10 = 无效，不做
  • 反弹绿K太长太强 = 多头力量强，不适合这次做空

教科书级空头排列Reject MA10。从684.93跌至682.24，连续实心红K只有下影线，中途绿K反弹上影线碰到MA10被压回，趋势延续。这是信号A最完整的形态。
实盘参考 — 图9（01/07 12:07 · 1分钟）
多头排列Support MA10。价格从692.275涨至693.87，中途红K回调下影线踩到MA10被撑住，随后绿K确认继续上涨。注意看红K的下影线是否真正触及MA10，没碰到就不算。
04
进场信号B — 大空间信号
和信号A同样是Reject MA10进场。区别在于多了三个额外条件，使得下方空间更大。两者本质是同一个信号，只是信号B出现的那次Reject恰好同时打穿了MA50，且下方空旷。
信号B完整形态 — 2-3根红K setup → 测试MA10 → Reject同时跌破MA50 → 下方空旷
五步条件缺一不可
空头排列成型
↓
先出现2-3根红K的setup
↓
Reject MA10，且那根K同时跌破MA50
↓
下方VWAP和MA200都离得很远，没有关卡拦着
↓
5分钟K线图需要形成支撑或跌破，近处没有关卡拦着
注意均线缠绕：MA10、MA20、MA50挤在一起价格来回穿 → 不做。必须等均线清晰发散，排列稳定后才找进场点。缠绕期间进场没有依据。

价格实体收回MA50上方 → 立刻出场，进场依据消失
目标位
下方最近关卡（VWAP或MA200），分批止盈
第一根绿K出现后绝对不追。大概率只有这一段，绿K之后进场是亏钱的。

三条重要关卡（MA50 / MA200 / VWAP）
三条线本质相同，都是有实质力度的支撑/阻力关卡。用途完全一样，只是强度不同。MA200突破后空间最大。
关卡的支撑与阻力作用
进场前 — 看空间够不够
目标方向最近的关卡在哪里？进场后没走几步就碰到 → 空间太小，不做。
持仓中 — 接近关卡要警惕
持PUT接近MA50/MA200/VWAP → 小心支撑反弹，准备减仓。
持CALL接近这三条线 → 小心阻力压制，准备减仓。
MA200的特殊地位
价格在MA200上方 → 多头背景，优先找CALL
价格在MA200下方 → 空头背景，优先找PUT
价格在MA200附近反复 → 不做或极轻仓

Reject MA10同时Reject VWAP → 双重确认，信号更强。

08
1分钟 + 5分钟配合
1
先开5分钟图 → 确认大方向。5分钟没有趋势 = 等，不动。
2
看5分钟关卡位置 → 目标方向有没有紧挨着的关卡？太近不做。
3
切换1分钟图 → 等MA10的Reject或Support，盯到K线收完确认。
4
进场后 → 1分钟盯MA10，5分钟影线变长就警惕出场。
5分钟越强，可以拿越久
5分钟连续大实心K均线极度发散 → 可以多拿几根K。5分钟趋势一般 → 快进快出，不要贪。
实盘参考 — 图5（01/30 12:10 · 5分钟）
5分钟级别极强空头排列，均线极度发散，连续大实心红K只有小下影线。这种大趋势下，切到1分钟找每次Reject MA10进场，可以多拿几根K再出。
09
进场前八步检查 — 全部通过才下单
任何一条让你犹豫，答案就是不做。
1
5分钟有趋势吗？ 排列清晰发散？没有 → 停手。
2
均线有缠绕吗？ MA线缠在一起 → 不做，等发散。
3
VWAP站哪边？ 和趋势方向一致？
4
目标方向有关卡拦着吗？ MA50、MA200、VWAP太近 → 不做。
5
MA10给信号了吗？ 影线或实体真正触及MA10了？还没 → 等。
6
确认K收完了吗？ 没收完 → 等，哪怕少吃几分钱。
7
K线质量好不好？ 影线开始变长，实体变小 → 等下一根。
8
IV高不高？ 高了就更挑剔，不够完美就不做。
10
止损规则
进场逻辑 = 出场逻辑。进场的理由消失，立刻出场。没有"再等等"。
进场原因止损条件（立刻出）
空头排列 Reject MA10 买PUT绿K实体完全突破MA10
多头排列 Support MA10 买CALL红K实体完全跌破MA10
信号B，Reject MA10+跌破MA50价格实体收回MA50上方
跌破MA200做空价格实体收回MA200上方
突破MA200做多价格跌破MA200
11
止盈规则
1
分批止盈 → 分2-3次出，不要一次全卖。
2
趋势衰竭信号出现时减仓 → 影线变长、K线不再创新低、红绿开始交替 → 开始出。
3
接近5分钟关卡减仓 → MA50、MA200、VWAP附近分批出。
4
尾盘不贪 → 有利润就走。
5
Robinhood注意 → 必须在下跌/上涨过程中卖出，回头卖会滑点严重或卖不出。
卖飞了不可惜。利润回撤比亏损更伤心态。
12
什么时候绝对不做
  • 5分钟没有趋势，均线缠绕 → 不做，等出方向
  • 均线之间有压制，价格在关卡群里穿来穿去 → 不做
  • 价格在MA200附近反复 → 不做
  • 开盘前30分钟（9:30-10:00）→ 通常震荡，等10点后
  • 连续长影线，红绿交替 → 不做
  • IV太高 → 更挑剔或不做
  • 看不明白当前情况 → 不做
  • 进场点离关卡太近 → 不做
  • 趋势已走很长，价格已很低/很高 → 不吃鱼尾
  • 刚做错一单心态不稳 → 先停，不要急着找回
  • 没想清楚进场理由就想进 → 不做
不赚好过亏钱。一天什么都不做，远好过乱做一堆亏损的单。
13
早上开盘特别规则
开盘通常有一段震荡，均线乱、方向不明。等10:30甚至11点之后方向清晰再看。

如果开盘直接出现两根大阳/大阴柱突破MA200 → 例外，可以考虑跟进，但要确认1分钟图形态。
早上磨了很久没方向 → 下午往往反而好做。不要因为早上没做就急躁，机会后面有的是。
14
仓位管理
每天开单数量
1 — 2单
最多不超过3单。多了头昏眼花，越做越错。
仓位原则
不确定 → 轻仓
信号极完美 → 正常仓位
亏损状态 → 绝对不充值
  • 不要因为别人暴利就想重仓，先保证稳定赚钱
  • 不要不断补仓，会恶性循环
  • 不稳定盈利之前不充值
15
心态管理
技术好掌握，掌握了就不太会忘。心态每天都要拧一拧。
  • 卖飞了不可惜，机会永远有下一个
  • 买定离手，出了就不要再想
  • 盯盘累了就休息，累时操作最容易变形
  • 今天没机会就不做，等明天
  • 不要overtrade，盈利再吐回比直接亏损更伤心态
  • 不要急着找回刚亏的那笔，下一单更容易错
  • 不要看别人操作就乱跟，找自己适合的方法
  • 市场有时会故意骗你，被骗出来就行，不要赌气
市场只会奖励遵守纪律的人。在没看到信号时进场，亏钱是活该。
