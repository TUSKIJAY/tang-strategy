## 0. 本文档的使用边界

这份笔记分成两层：

1. **人工交易判断层**：用于解释 Tang 的实际看盘逻辑，允许结合上下文、前序争议位置、回测质量和盘面强弱做判断。
2. **项目实现层**：用于教学系统、checkpoint、训练数据和静态页面展示，必须有明确字段、阈值和可复现规则。

今日更新里最重要的变化是：**MA50 不能被当成机械支撑或机械防线，必须看它之前是否真的被市场验证过。**

## 1. 核心入场公式

**入点：盯 5min MA10 的价格；只要不破 5min MA10，且 1min MA50 没有被有效跌破，就维持多头思路。**

但这里的 `1min MA50` 需要具体分析：

- 如果前面已经在 MA50 附近得到过支撑，可以观察它是否再次发挥支撑。
- 如果 MA50 从未被测试、没有争议历史、也没有明显反应，就不能机械地把它当作有效防线。
- 是否“破 MA50”，不能只看单根影线，要结合实体、回测、下一根确认 K 和当时的大级别方向。

### 1.1 三条核心线

| 角色 | 用途 | 判断重点 |
| :--- | :--- | :--- |
| 5min MA10 | 主入场参考线 | 不破则趋势思路仍在 |
| 1min MA50 | 次级防线 | 必须看前面是否被市场验证过 |
| MA50 / MA200 / VWAP | 关卡与目标位 | 用于判断支撑、阻力、止盈目标和逻辑失效 |

### 1.2 对应交易推论

- 价格回踩 5min MA10 撑住，多头仍有延续预期。
- 价格反抽 5min MA10 后被压回，空头延续概率提高。
- 目标位通常不是随便设，而是看“上一次想突破但没成功的位置”或最近明显关卡。
- 离关键支撑太远不追，离关键压力太近不做多。

## 2. 入场决策树

任何一次交易都先按顺序过一遍。越靠前的问题越基础，前面不过关，后面就不用硬找理由。

### 2.1 开单前

1. **找到关键点位**

   先锁定 VWAP、MA50、MA200、5min MA10 等候选关卡。

2. **验证这个点位是否真的关键**

   问题不是“价格碰到了均线没有”，而是：

   - 前面是否在这里发生过争议？
   - 是否曾经被支撑、压制或反复测试？
   - 市场是否在这个位置出现过明显反应？

   从未被测试过的均线，不应直接视为强支撑或强阻力。

3. **确认大级别方向**

   5min 与 1min 冲突时，优先看 5min。看不懂大级别时，空仓比强行解释更好。

4. **判断当前是否正在突破、跌破或回测**

   没有回测的试探性突破容易失败。有效突破或跌破最好具备：

   - 实体跨越关键线。
   - 回测关键线。
   - 回测后不再破回去。
   - 下一根 K 继续朝预期方向走。

5. **检查前路阻力或支撑**

   - 做多时，看上方是否有 MA50、MA200、VWAP 等密集压制。
   - 做空时，看下方是否有 MA50、MA200、VWAP 等密集支撑。
   - “头顶全是天花板”时不要强行做多。

6. **等待反弹 K 或拒绝 K**

   - 支撑位附近，观察是否出现有效绿 K 或下影支撑。
   - 压力位附近，观察是否出现有效红 K 或反抽失败。

   价格到达关键位不等于信号成立，必须有市场反应。

### 2.2 开单后

7. **验证是否顺势走强**

   买入后应该比较快地沿关键位走出预期方向。如果价格长期粘在入场点附近反复拉锯，说明动能不足。

8. **逻辑失效必须立刻处理**

   如果买入后没有朝预期方向走，反而正式突破了你的关键位，就要重点观察是否发生反向回测：

   - 原支撑被跌破并回测失败，支撑变阻力。
   - 原阻力被突破并回测成功，阻力变支撑。
   - 反向回测成立后，原交易逻辑已经失效。

   这时应该退出，不加仓、不扛、不等。

| 指标 | 角色 | 备注 |
| :--- | :--- | :--- |

| MA20 | 短期防线，也会框出窄区间 | 常与 VWAP 形成上下夹击 |

## 4. 关键规则定义

### 4.1 顺势优先

- 顺势是最核心的过滤条件。
- 大多数逆势交易即使看上去盈亏比好，也容易失败。
- 没看懂当前走势时，不要反手。
- 5min 与 1min 冲突时，优先相信更大级别。

### 4.2 有效突破 / 有效跌破

不要把影线当作突破或跌破。有效信号最好满足：

1. 看实体，不看单纯影线。
2. 实体开在或收在关键线另一侧。
3. 出现回测。
4. 回测不破。
5. 下一根确认 K 继续沿预期方向走。

Tang 原话口径可以概括为：**跌破 = 实体开在下方，并最好经过一次回测。**

### 4.3 MA50 的新增判断口径

旧口径容易被理解成：“1min 不破 MA50 就一直看多。”

今日更新后应改成：

**1min MA50 是次级防线，但前提是这个 MA50 已经被市场验证为有效位置。**

具体判断：

- 如果前面在 MA50 得到过支撑，再次回踩 MA50 时可以观察是否继续撑住。
- 如果前面 MA50 没有产生过明显争议，就不能仅凭“价格接近 MA50”认定有支撑。
- 如果实体跌破 MA50 后反向回测失败，多头逻辑失效。
- 如果只是影线刺破后快速拉回，仍要结合下一根确认 K 判断。

### 4.4 支撑阻力互换

- 阻力被突破并回测成功后，可以转为支撑。
- 支撑被跌破并反向回测失败后，可以转为阻力。
- MA50、MA200、VWAP 都经常发生这种互换。

### 4.5 多次尝试与力量衰减

趋势反转通常不是一次完成的，常见确认方式包括：

- 低点逐渐抬高，说明空方力量减弱。
- 高点逐渐降低，说明多方力量减弱。
- W 底或 M 顶形成后，第三次推进仍失败，原方向力量可能已经衰竭。
- 原趋势已经走了很远时，第一次反向尝试通常不足以完成大级别反转。

### 4.6 窄幅震荡区间

当价格被 VWAP、MA20、MA50、MA200 等均线挤在很窄区间内时，不要提前猜方向。

更好的处理方式：

- 等价格彻底走出区间。
- 等关键均线突破或跌破后回测。
- 通过“跌不下去”或“涨不上去”判断末期力量。
- 窄区间末期的 K 线很容易迷惑，必须等确认。

## 5. 开盘 30 分钟口径修正

今日 summary 把旧版“开盘 30 分钟内禁入”改成了“开盘 30 分钟内慎入”。这里需要拆成两层，避免和项目实现冲突。

### 5.1 人工交易口径

开盘 30 分钟内不是绝对不能看，但要更谨慎：

- 开盘背景不稳定，假突破和假跌破更多。
- 除非有非常清晰的 opening gap 专案或强背景，否则不急着开单。
- 可以观察，不要过早重仓判断。

### 5.2 当前项目实现口径

当前 `prepare_data.py` 仍按硬禁入处理：

- `signal_time < 10:00` 进入 `forbidden_flags`
- 除 `opening_gap` 专案外，教学系统不应把它标为普通可交易信号

因此项目文案建议写成：

**人工复盘口径是慎入；当前系统实现仍按禁入处理，除 opening_gap 专案外，10:00 前不开普通信号。**

## 6. 禁做条件

| 禁做条件 | 判断口径 | 原因 |
| :--- | :--- | :--- |
| 大级别看不懂 | 5min 与 1min 冲突且无法判断 | 避免逆势硬做 |
| 均线缠绕 | 多条均线密集、方向不明 | 方向不清，信号质量低 |
| 上方阻力密集时做多 | MA50 / MA200 / VWAP 等压在上方 | 目标空间不足 |
| 下方支撑密集时做空 | 多条关键线在下方 | 下跌空间不足 |
| 离支撑太远追多 | 止损空间过大 | 盈亏比变差 |
| 离压力太远追空 | 止损空间过大 | 盈亏比变差 |
| 反向回测已成立还扛单 | 原逻辑已经失效 | 应立即退出 |
| 普通信号出现在 10:00 前 | 当前项目实现硬禁入 | 除 opening_gap 专案外不做 |

## 7. 实战案例映射

### 案例 A：MA50 作为下午行情分界线

- 11:50 撑 MA50，开启升幅。
- 12:30 跌破 MA50，推断同等级别大跌幅。
- 10:14 VWAP 处被拒绝，随后形成 W 底。
- 10:57 回测 VWAP 确认反转。
- 9:56、10:24、10:41 三个低点逐次抬高，说明空方力量减弱。

对应规则：

- MA50 可作为日内分界线，但必须看它是否已经被价格验证。
- VWAP 被突破并回测成功后，阻力转支撑。
- W 底和低点抬高共同说明力量衰减。

### 案例 B：MA200 决战窄区间

- 11:30 到 13:14 一直被压制在 MA200 下方。
- 真正突破 MA200 后才开启新行情。
- 13:02 看似空头，但实际价格跌不下去，决定了后续多头突破。
- 13:25 需要小回调测试支撑，确认首次突破 MA200 是否能撑住。

对应规则：

- 窄区间不要提前猜方向。
- 关键均线突破后要看回测。
- “跌不下去”本身就是空方衰减信号。

### 案例 C：上方均线密集不能强行做多

- 价格从 711 沿多条均线下压到 708.95。
- MA5、MA10、MA20、MA30、MA50、MA200、VWAP 多数在价格上方。
- 这种情况不应该强行进场做多。

对应规则：

- 前路阻力密集时，目标空间不足。
- 即使出现短线反弹，也很容易被上方均线压回。

### 案例 D：做空设想的前置条件

- 多头要先弱下去，否则空头排列会被破坏。
- 5min 级别要被压住。
- 最好在关键价格下方稳定。
- 最好 5min 被 MA20 reject，更可能走单边。

对应规则：

- 做空也必须顺势。
- 不能在多头仍强时提前猜顶。
- Reject 需要反抽失败，而不是价格单纯靠近均线。

### 案例 E：多头力量衰减

- 价格冲高到 697.80 后出现大阴线，回到 696.36。
- 这说明多方开始变弱。

对应规则：

- 高点降低或冲高失败，是多头力量衰减的早期信号。
- 后续需要结合关键线跌破与回测确认，不能只靠单根 K 线反手。

## 8. 项目实现映射

项目权威实现仍以 `src/prepare_data.py` 为准。

### 8.1 三类核心信号

| 项目术语 | 代码定义 | Tang 规则对应 |
| :--- | :--- | :--- |
| Support MA10 | HA 下影触 MA10，实体仍稳上方，下一根延续上涨 | MA10 撑住，期待多头延续 |
| Reject MA10 | HA 绿色反抽触 MA10，实体仍被压在 MA10 下方，下一根延续下跌 | 反抽 MA10 后被压回 |
| 信号 B | 开盘 > MA50，收盘同时 < MA10 且 < MA50 | 双线跌破，空头加强 |

注意：Reject MA10 在代码中强制要求绿色反抽。这是项目强化定义，不是 Tang 原文中明确说出的完整条件。

### 8.2 Checkpoint 映射

| # | Checkpoint Key | 标签 | Tang 规则对应 |
| :--- | :--- | :--- | :--- |
| 1 | `trend_ok` | 5min 趋势确认 | 大级别优先 |
| 2 | `ma_alignment_ok` | 均线排列方向 | 顺势核心 |
| 3 | `touch_ma10` | K 线触及 MA10 | 入点盯 5min MA10 |
| 4 | `body_not_cross` | 实体未穿越 | 看实体，不看影线 |
| 5 | `confirm_bar` | 确认 K 延续方向 | 回测后确认 |

### 8.3 今日更新对项目的潜在影响

今日更新不一定要求立刻改代码，但会影响后续教学解释和 checkpoint 文案：

1. `1min MA50` 应从“固定防线”改写为“经市场验证后的次级防线”。
2. 规则说明中应增加“前序争议位置 / 前次支撑历史”的概念。
3. 开盘 30 分钟需要区分人工口径和项目实现口径。
4. 如果未来要把“慎入”做进系统，需要新增风险等级，而不是直接取消 `forbidden_flags`。

## 9. 一句话总纲

Tang 的核心不是“碰到某条均线就买卖”，而是：

**先看大级别方向，再找被市场验证过的关键位，等待实体与回测确认；进场后若不能顺势走强，且反向回测成立，就立即承认逻辑失效。**
